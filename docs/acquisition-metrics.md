# HallPass Acquisition Metrics

## Purpose

The purpose of this acquisition metrics plan is to measure how effectively the HallPass landing page attracts students, encourages them to explore the prototype, and collects useful feedback for future improvements.

The metrics focus on the complete user journey:

Landing Page Visitor
→ CTA Click
→ Prototype Demo
→ User Feedback
→ Conversion

---

# Metric Definitions

| Metric ID | Metric | Category | Definition | Formula | Data Source | Success Target |
|-----------|----------|----------|------------|----------|-------------|----------------|
| M-01 | Landing Page Visitors | Awareness | Number of users who open the HallPass landing page. | Count all visitors. | Manual log / browser analytics / spreadsheet | 50 visitors |
| M-02 | CTA Click Rate | Action | Number of users who click "Try HallPass Demo" or "Open HallPass". | CTA Clicks ÷ Visitors × 100 | JavaScript click counter / spreadsheet | 40% |
| M-03 | Prototype Demo Views | Engagement | Number of users who successfully enter the HallPass prototype from the landing page. | Count demo page visits | Prototype logs / manual tracking | 30 users |
| M-04 | Feedback Responses | Feedback | Number of users who provide comments or suggestions after trying the prototype. | Count submitted feedback forms | Google Form / Spreadsheet | 10 responses |
| M-05 | Conversion Rate | Conversion | Percentage of visitors who complete the intended action (open and use the prototype). | Demo Users ÷ Visitors × 100 | Spreadsheet | 25% |

---

# Measurement Plan

## M-01 Landing Page Visitors

Purpose:
Measure awareness of HallPass.

Collection Method:
Record each visitor manually or simulate using browser logs.

Frequency:
Daily during testing.

---

## M-02 CTA Click Rate

Purpose:
Determine whether visitors are interested enough to try the prototype.

Collection Method:
Track clicks on:

- Try HallPass Demo
- Open HallPass

Formula:

CTA Click Rate = CTA Clicks / Landing Page Visitors × 100

---

## M-03 Prototype Demo Views

Purpose:
Measure how many visitors actually explore the HallPass system.

Collection Method:

Count users who successfully open the prototype after clicking the CTA.

Formula:

Demo View Rate = Demo Views / CTA Clicks × 100

---

## M-04 Feedback Responses

Purpose:

Measure user willingness to provide suggestions after using HallPass.

Collection Method:

Google Form or manual feedback sheet.

Formula:

Feedback Rate = Feedback Responses / Demo Views × 100

---

## M-05 Conversion Rate

Purpose:

Measure how many visitors become active prototype users.

Collection Method:

Compare landing page visitors with users who entered the prototype.

Formula:

Conversion Rate = Prototype Demo Views / Landing Page Visitors × 100

---

# Data Collection Method

The HallPass prototype does not currently use a backend database.

Therefore, acquisition metrics will be collected using:

- Manual spreadsheet tracking
- JavaScript click counter (if implemented)
- Prototype navigation logs
- Google Form feedback
- Browser localStorage (optional)

---

# Success Criteria

| Metric | Target |
|---------|---------|
| Landing Page Visitors | ≥ 50 |
| CTA Click Rate | ≥ 40% |
| Demo Views | ≥ 30 |
| Feedback Responses | ≥ 10 |
| Conversion Rate | ≥ 25% |

---

# Improvement Plan

If the target metrics are not achieved, the team will:

- Improve the landing page headline.
- Make the CTA button more visible.
- Simplify the prototype navigation.
- Improve feature descriptions.
- Promote HallPass through additional student channels such as class groups and student clubs.
