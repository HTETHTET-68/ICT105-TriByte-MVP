# User Consent Statement

This HallPass prototype is created for **ICT105 learning purposes** by the **TriByte Team**. We invite users to test the prototype and provide feedback on its usability, functionality, and overall user experience. The information collected will be used only to evaluate and improve the HallPass prototype as part of the ICT105 coursework. Users should **not** provide sensitive personal information such as identification numbers, financial information, medical information, or passwords within reviews or feedback. Participation in the prototype testing is completely voluntary, and users may stop participating at any time.

## Data Collected

- Name, nickname, or anonymous tester ID
- Email address (if account registration is used)
- User role (Student or Administrator)
- Feedback score
- Comments about usability
- Task completion result
- Review content submitted during testing
- Review rating (1–5 stars)

## Data Use

The collected data will be used only for:

- Evaluating the HallPass prototype during ICT105 coursework
- Analyzing usability and task completion results
- Improving the prototype based on user feedback
- Supporting customer validation and MVP evaluation
- Preparing the final project report and presentation

All collected information will be used solely for educational purposes and will not be shared with third parties outside the ICT105 course without the user's permission.
