# Customer Validation Summary

# 1. Project Title

**HallPass – Dormitory and Cafeteria Reviews**

---

# 2. Prototype Tested

The MVP prototype tested was the HallPass web application developed using HTML, CSS, and JavaScript. The prototype allows students to browse dormitory reviews, cafeteria reviews, campus survival guides, view review details, register/login, and submit reviews using a simulated frontend with local storage.

- **Prototype Version:** MVP Version 2
- **Prototype Link or Screenshot Location:** `/prototype/` and `/screenshots/`
- **Main Tasks Tested:**
  - Understand the purpose of HallPass
  - Navigate between pages
  - Browse dormitory and cafeteria reviews
  - Read review details
  - Register/Login
  - Submit a review
- **Related Requirements:**
  - FR-01 Homepage
  - FR-02 Navigation
  - FR-03 Login & Registration
  - FR-04 Campus Guide
  - FR-05 Dormitory Reviews
  - FR-06 Cafeteria Reviews
  - FR-07 Review Details
  - FR-08 Review Submission
  - FR-10 Review Form Validation
  - FR-14 Review Storage (Local Storage)

---

# 3. Test Users

| Test User ID | User Role | Why this user is relevant |
|---|---|---|
| TU-01 | First-year Student | Primary target user looking for campus information |
| TU-02 | International Student | Needs reliable campus guidance and reviews |
| TU-03 | Exchange Student | Evaluates usability for new campus users |

# 4. Validation Method

The validation was conducted through usability testing using the HallPass MVP prototype. Participants were asked to complete common tasks while researchers observed task completion, completion time, usability ratings, confusion points, and qualitative feedback.

- **Testing Method:** Task-based usability testing
- **Date/Time:** Lab 08 MVP Validation Session
- **Location:** University Computer Laboratory / Online Demonstration
- **Number of Validation Records:** 200
- **Data Collected:**
  - Task completion
  - Completion time
  - Ease-of-use rating
  - Usefulness rating
  - Interest level
  - Confusion points
  - User comments

---

# 5. Summary of Results

| Metric | Result | Interpretation |
|---|---:|---|
| Total validation records | 200 | Sufficient validation data collected |
| Task success rate | **85%** | Exceeded the project success target of 80% |
| Average ease-of-use score | **3.99 / 5** | Users generally found the prototype easy to use |
| Average usefulness score | **4.30 / 5** | Users believed HallPass would be useful |
| Average interest level | **4.34 / 5** | Strong interest in using HallPass after launch |
| Most common confusion point | Login and signup navigation | Indicates the authentication flow needs improvement |

---

# 6. Key User Comments

Several common themes appeared throughout the validation process.

### Positive Feedback

- Users immediately understood the purpose of HallPass.
- Dormitory and cafeteria reviews were considered useful for new students.
- Campus survival guides were valuable for first-year and international students.
- Review details helped users compare accommodation and dining options.
- The review submission page was simple and easy to understand.

### Repeated Suggestions

- Login and signup navigation could be clearer.
- Search and filtering should be more visible.
- Ratings should stand out more on review cards.
- More campus locations and review categories should be added.
- Additional student-generated content would increase usefulness.

---

# 7. Affected Requirements

| Requirement ID | Evidence Found | Required Prototype Improvement |
|---|---|---|
| FR-02 | Some users required additional time to locate certain pages | Improve navigation visibility and menu organization |
| FR-03 | Login and signup caused the highest confusion | Simplify authentication flow and improve page transitions |
| FR-06 | Search/filter controls were not immediately noticeable | Improve filter placement and search interface |
| FR-07 | Users requested more visible ratings and review summaries | Enhance review card layout and visual hierarchy |
| FR-08 | Review submission was completed successfully but users requested additional review categories | Expand review categories and improve form guidance |

---

# 8. Conclusion

Overall, the HallPass MVP is **validated**.

The prototype exceeded its target success rate with an **85% task completion rate**, while users reported high usefulness (**4.30/5**) and strong interest (**4.34/5**) in using the system. Feedback confirms that HallPass effectively addresses the needs of first-year, international, and exchange students by providing accessible dormitory reviews, cafeteria reviews, and campus guidance.

The primary improvements identified involve the login/signup workflow, navigation clarity, and search functionality. These enhancements should be implemented before progressing to the next prototype iteration. The validation results provide strong evidence that the project direction is appropriate and should continue with incremental usability improvements rather than major redesign.
