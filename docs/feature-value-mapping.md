# Reflection

### Which feature creates the strongest user value?

The **Dormitory Reviews** and **Campus Survival Guide** create the strongest user value because they directly address the main problem faced by new students—finding reliable information about accommodation and campus life. These features help students make informed decisions and adjust to university life more confidently.

### Which feature creates the strongest business or operational value?

The **Write Review** feature creates the strongest operational value because it allows students to continuously contribute new content. As more reviews are submitted, the platform becomes more valuable, relevant, and sustainable without requiring administrators to create all of the information themselves.

### Which required feature is still weak or unclear?

The **Admin Dashboard** is currently the weakest feature because the prototype only demonstrates dashboard statistics and moderation-related information. It does not yet implement a complete moderation workflow such as approving, rejecting, or editing submitted reviews. These functions can be considered for future development beyond the current MVP.
