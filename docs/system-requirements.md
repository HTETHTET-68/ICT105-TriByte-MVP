# HallPass Requirement Traceability

This section explains how the HallPass MVP satisfies each minimum functional requirement specified by the ICT105 Lab 04 template.

| Req ID | HallPass Implementation |
| --- | --- |
| **FR-01** | Landing page introduces HallPass, explains its purpose, target users (first-year, international, and exchange students), and provides quick access to campus information. |
| **FR-02** | Users can navigate from the homepage → search for dormitories/cafeterias → view reviews → submit their own review. |
| **FR-03** | Users can submit reviews for dormitories and cafeterias, including ratings and written comments. |
| **FR-04** | Submitted reviews are stored using the project's selected data storage solution (e.g., Firebase, Google Sheets, JSON, or database). |
| **FR-05** | Users can browse existing dormitory and cafeteria reviews through organized listings. |
| **FR-06** | Users can search or filter reviews by dormitory, cafeteria, category, or keyword. |
| **FR-07** | Each review has a dedicated detail page displaying ratings, comments, and related information. |
| **FR-08** | Reviews display their status (e.g., Pending Review, Approved, Published) to support moderation. |
| **FR-09** | Administrators can approve, edit, or remove inappropriate reviews before publication. |
| **FR-10** | The review submission form validates required fields, ratings, and prevents incomplete submissions. |
| **FR-11** | Users receive confirmation messages after successfully submitting a review or when validation errors occur. |
| **FR-12** | An admin dashboard summarizes total reviews, average ratings, most-reviewed dormitories, and popular cafeterias. |
| **FR-13** | All pages follow a consistent navigation structure, color palette, typography, and interface design. |
| **FR-14** | The HallPass interface is designed responsively for both desktop and mobile devices. |
| **FR-15** | HallPass collects only essential information and avoids unnecessary personal data, promoting responsible data handling. |
| **FR-16** | Every prototype screen is directly linked to the Lab 04 user stories, MVP feature list, and validated customer needs identified during Lab 03. |

## Target Users

- First-year university students
- International students
- Exchange students

## Problem Statement

Students often spend excessive time searching for reliable campus information because existing resources are scattered across multiple platforms, outdated, or difficult to verify.

## Proposed Solution

HallPass centralizes trusted student-generated information about dormitories, cafeterias, and campus life into a single searchable platform, helping students make informed decisions quickly and confidently.
