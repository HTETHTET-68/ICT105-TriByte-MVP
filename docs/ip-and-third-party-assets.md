# IP Summary

This project contains both original work and third-party resources.

## Original Assets

- HTML, CSS, and JavaScript source code developed by the TriByte team.
- HallPass website interface, responsive layouts, and navigation design.
- Prototype wireframes, review pages, and dashboard interface.
- Project documentation, customer validation reports, analytics documents, and technical diagrams.
- Customer validation dataset, Power BI dashboard, and MVP experiment materials created by the project team.

## Third-Party Assets

The project uses the following third-party resources:

- **Google Fonts (Inter)** (SIL Open Font License) for website typography.
- **Unsplash** (Unsplash License) for the homepage background image.
- **Browser Local Storage API** (Web Standard API) for simulating user authentication and review storage.
- **GitHub** for source code management and team collaboration.
- **Microsoft Power BI Desktop** for customer validation analytics and dashboard visualization.

These resources are used according to their respective licenses or terms of use and remain the property of their original owners.

## External APIs and Datasets

The HallPass prototype does not use external APIs or public datasets. All review data, customer validation records, and sample information were created by the project team for demonstration, testing, and educational purposes only.
