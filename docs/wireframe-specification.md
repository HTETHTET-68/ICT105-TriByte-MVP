# Current Prototype Screen Specification

## Design Direction

HallPass uses a warm neutral background, navy text, soft gold highlights, rounded cards, shared navigation, and responsive layouts for a student-friendly appearance.

| Screen | Current content and behavior | Requirements |
|---|---|---|
| Homepage | HallPass purpose, audience, main actions, statistics, featured reviews | FR-01, FR-02, FR-12, FR-13 |
| Login | Hard-coded student/admin demonstration credentials and redirects | FR-03, FR-12 |
| Signup | Required name, email, and password fields; simulated account stored in the browser | FR-03, FR-12 |
| Dorm Reviews | Dorm cards, title search, minimum-rating filter, visible non-functional sort control | FR-04, FR-06, FR-12, FR-13 |
| Cafeteria Reviews | Food cards, title search, minimum-rating filter, visible non-functional sort control | FR-05, FR-06, FR-12, FR-13 |
| Review Details | Selected review title, category, rating, description, price, location, and fixed sample comments | FR-07, FR-12 |
| Write Review | Login protection, required category/rating/title/text fields, optional price/location/photo picker, local submission | FR-08, FR-10, FR-14 |
| Survival Guide | Static organized campus-survival topics | FR-09, FR-12 |
| Dashboard | Review totals, locally submitted review rows, and demonstration Approve/Reject messages | FR-11, FR-12 |

The current prototype contains nine HTML pages. Privacy Consent, My Reviews, and Report Review screens are proposed future additions and are not represented as existing screens.
