# Lab 04 - MVP Feature List

## MVP Decision Rule

The MVP should include the minimum set of features required to validate that HallPass helps first-year, international, and exchange students find trustworthy campus information more quickly than existing methods.

## Must-Have Features

* Homepage / Landing Screen
* Search Dormitories
* Browse Cafeteria Reviews
* View Detailed Reviews
* Submit Dormitory and Cafeteria Reviews
* Search and Filter Reviews

These features directly address the main problem identified during customer discovery: students spend excessive time searching through scattered and unreliable sources for campus information.


## Should-Have Features

* Campus Survival Guide
* Admin Review Moderation
* User Rating System (1–5 Stars)

These features improve usability and trustworthiness but are not essential to demonstrating the core problem–solution fit.


## Could-Have / Future Features

* Favorite / Save Reviews
* Interactive Campus Map

These features would enhance the user experience after validating the MVP but are not required for the initial prototype.


## Not in MVP

The following features are intentionally excluded from the MVP because they are either technically complex or not strongly supported by customer discovery evidence:

* AI-powered recommendations (US-19)
* Real-time student chat (US-18)
* Push notifications
* Social networking features
* Gamification (badges, rewards, points)

Although these features may improve user engagement in future versions, they do not directly contribute to validating HallPass's primary value proposition of providing reliable, centralized campus information. Excluding them allows the team to focus on delivering a simple, usable, and evidence-based MVP within the semester timeline.
