# MVP Experiment Plan

## 1. Group and Project Information

- **Group Name:** TriByte
- **Project Title:** HallPass – Dormitory and Cafeteria Reviews
- **Repository Link:** https://github.com/HTETHTET-68/ICT105-TriByte-MVP.git
- **Main Target Users:** First-Year University Students, International Students, and Exchange Students
- **Prototype Platform:** Website (HTML, CSS, JavaScript)

---

## 2. Experiment Objective

> We want to test whether first-year, international, and exchange students can easily find trustworthy dormitory reviews, cafeteria reviews, and campus guidance, as well as successfully submit their own reviews using the HallPass prototype without assistance.

## 4. MVP Experiment Type

### Selected Experiment Type

- Simple Web Prototype
- Clickable Prototype
- Form-Based Simulation

### Reason for Selection

HallPass has been developed as an interactive website using HTML, CSS, and JavaScript with Local Storage. Test users can navigate between pages, browse reviews, read campus guides, and submit reviews. Combining a clickable prototype with a form-based simulation allows the team to evaluate navigation, usability, and the review submission process before implementing a backend database.

---


## 5. Test Users

The MVP experiment will involve five participants selected to represent the primary user groups of HallPass. These participants match the project's identified target users and key stakeholder responsible for content moderation.

| Tester Code | Tester Type | Campus Role | Experience with HallPass | Reason for Selection |
|--------------|-------------|-------------|--------------------------|----------------------|
| T01 | Student | First-year Undergraduate | Never used HallPass before | Represents new students seeking reliable dormitory reviews, cafeteria reviews, and campus guidance before making campus decisions. |
| T02 | Student | International Student | New to the university | Represents international students who need trusted campus information and guidance to adapt quickly to a new environment. |
| T03 | Student | Exchange Student | First semester on campus | Represents short-term students who need quick access to dormitory, cafeteria, and campus information during their exchange period. |
| T04 | Student | Senior Undergraduate | Experienced campus student | Represents experienced students who contribute reviews, ratings, and campus survival tips while evaluating the review submission process. |

**Total Testers:** **5**

---

## 6. Experiment Procedure Summary

Each participant will complete the following tasks:

1. Open the HallPass homepage.
2. Browse the Dormitory Reviews page.
3. Search for a dormitory review.
4. Open and read a review.
5. Browse the Cafeteria Reviews page.
6. Read the Campus Guide.
7. Log in using the provided demo account.
8. Submit a new review using the review form.
9. Verify that the review appears successfully.
10. Visit the Dashboard.
11. Complete the feedback form.

During the experiment, the team will record:

- Task completion rate
- Time taken to complete each task
- User navigation difficulties
- Confusing interface elements
- Errors encountered
- Suggestions for improvement

---

## 7. Expected Learning

After conducting the MVP experiment, the team expects to determine:

- Whether students can easily navigate the HallPass website without assistance.
- Whether dormitory and cafeteria reviews help students make informed decisions.
- Whether users can successfully submit reviews using the current interface.
- Whether the Campus Guide provides useful information for new students.
- Which features should be improved before developing the final prototype.
- Whether the MVP successfully addresses the needs of first-year, international, and exchange students.

The experiment results will help the team prioritize usability improvements and validate the core features before proceeding with deeper implementation.
